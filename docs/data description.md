## Что означает каждая колонка:
1. patient_id - идентификатор пациента
2. note - краткая клиническая характеристика пациента, на основании которой можно оценить, подходит ли он/она для участия в клиническом исследовании
3. trial_id - идентификатор клинического исследования, на которое отбирают пациентов
4. trial_title - название клинического исследования
5. trial_inclusion - критерии включения
6. trial_exclusion - критерии исключения
7. expert_eligibility - заключение эксперта о том, подходит ли пациент под исследование (included/excluded/not enough information/not excluded)
